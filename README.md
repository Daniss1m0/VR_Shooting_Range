# VR_Shooting_Range

Projekt stanowi **grę typu strzelnica (shooting range)** stworzoną w silniku **Unity** z obsługą gogli VR. Celem gracza jest zdobycie jak największej liczby punktów poprzez strzelanie do różnych celów.

## Zrealizowane funkcjonalności

* Obsługa VR (interakcja z obiektami 3D)
* Strzelanie do celów wirtualnych
* Możliwość rozbijania butelek i innych obiektów
* Różne poziomy trudności / etapy gry
* System punktacji i licznik wyników
* Proste UI wyświetlające wynik
